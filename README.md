# 罗小黑战记 · 设定集与年表

一个基于官方微博归档的非官方资料站：把 `@电影罗小黑战记2`（4974 条）与 `@罗小黑CAT`（1653 条）两个账号的微博、5609 张图片，整理成
**时间线 / 人物设定集 / 关系网 / 战记 1 / 战记 2 / 番外故事 / 漫画蓝溪镇** 七个部分。

## 打开方式

纯静态站点，无构建、无依赖：

```powershell
cd luoxiaohei-site
python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/
```

直接双击 `index.html` 也能看（`fetch` 未使用，数据以 `assets/data.js` 全局变量的形式加载）。

## 目录结构

```
luoxiaohei-site/
├─ index.html                 单页骨架（七个区块 + 弹窗 + 灯箱）
├─ assets/
│  ├─ css/style.css           全站样式（暗/亮双主题区块、响应式）
│  ├─ js/app.js               全部渲染逻辑（原生 JS，无框架）
│  ├─ data.js                 站点数据（window.LXH，由 build_site_data.py 生成）
│  ├─ img/                    海报、剧照、设定稿、漫画首话等 30 张图
│  └─ avatars/                20 个角色头像 512×512 + avatars.json（含来源与裁切框）
└─ README.md
```

## 数据来源与口径

- 归档脚本与原始数据在相邻目录：`../luoxiaohei2/`（电影官博）、`../luoxiaoheicat/`（罗小黑 CAT）。
- 微博抓取时间 2026-11-25；电影官博 4974 条为接口可及上限（账号显示 5107 条，差额为删除/不可见），罗小黑 CAT 1653 条（显示 1655 条，差 2 条为删除）。
- 「官微提及数」为两个账号全部正文中角色名的出现次数（含转发原文），仅作热度参考。
- 配音一栏只写可核实的公开信息；查不到的写「—（官微未公布）」，未做补全或推测。
- 图片版权归《罗小黑战记》原作方与寒木春华所有，本站仅作资料展示。

## 重新生成

```powershell
# 数据（读 ../luoxiaohei2/data/posts.json 与 ../luoxiaoheicat/data/posts.json）
python ..\build_site_data.py

# 图片（海报/剧照/设定稿按 SPEC 裁切，需要两个归档目录的 images/）
python ..\build_site_assets.py
```

`build_site_data.py` 与 `build_site_assets.py` 位于工作区根目录，`SPEC` 表里记录了每张图的来源文件与归一化裁切框。
